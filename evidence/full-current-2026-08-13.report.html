Method

  • Shared source of truth: all harnesses use the same geometry and layouts from spec/, with a seeded PRNG and no Math.random.
  • Measured submission: draw calls and triangles come from a WebGL probe rather than engine-reported statistics.
  • Blocking parity gate: real GPU, backbuffer size, equal inputs, sample count, visible output, and GPU timer validity must all pass.
  • GPU timing: GPU-timed cases use asynchronous backpressure with EXT_disjoint_timer_query_webgl2; the next frame waits for the current query result, and unsupported, insufficient, skipped, or disjoint samples are invalid.
  • CPU timing: CPU p95 measures the synchronous update-and-render submission call; timer callback intervals are diagnostic only.
  • Steady state: sampling starts after a minimum warmup and three converged CPU-p95 windows; heavy cases may extend to reach the sample floor.
  • Run order: load points are deterministically shuffled per repeat and engine order is counterbalanced.
  • Provenance: schema-v2 results embed the complete case matrix, contract, commit, lockfile hash, and browser environment.
  • Run isolation: every run receives a new browser context, page, WebGL context, and engine instance.
  • Headless with vsync disabled: the GPU gate rejects software rendering, and disabling vsync exposes frame times above display refresh.
